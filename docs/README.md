# Design Patterns: qısa bələdçi

Gang of Four-un 23 design pattern-i haqqında Azərbaycan dilində qısa kitab. Hər fəsil sadə həyat analogiyası ilə başlayır, problemi göstərir, həlli bu repodakı işlək Java kodu ilə addım-addım izah edir və tapşırıqla bitir.

## Mündəricat

**[Giriş: Design pattern nədir?](00-giris.md)**

### I hissə: Creational (yaradıcı) pattern-lər
1. [Singleton](01-singleton.md): tək nüsxə
2. [Factory Method](02-factory-method.md): yaratmanı alt siniflərə həvalə etmək
3. [Abstract Factory](03-abstract-factory.md): məhsul ailələri
4. [Builder](04-builder.md): addım-addım qurmaq
5. [Prototype](05-prototype.md): surətini çıxarmaq

### II hissə: Structural (struktur) pattern-lər
6. [Adapter](06-adapter.md): uyğunlaşdırıcı
7. [Bridge](07-bridge.md): iki ölçünü ayırmaq
8. [Composite](08-composite.md): ağac strukturları
9. [Decorator](09-decorator.md): qat-qat xüsusiyyət
10. [Facade](10-facade.md): sadə giriş qapısı
11. [Flyweight](11-flyweight.md): paylaşılan vəziyyət
12. [Proxy](12-proxy.md): nümayəndə

### III hissə: Behavioral (davranış) pattern-lər
13. [Chain of Responsibility](13-chain-of-responsibility.md): məsuliyyət zənciri
14. [Command](14-command.md): əmr obyekti və undo
15. [Interpreter](15-interpreter.md): kiçik dil
16. [Iterator](16-iterator.md): gəzmə
17. [Mediator](17-mediator.md): vasitəçi
18. [Memento](18-memento.md): save / load
19. [Observer](19-observer.md): abunəlik
20. [State](20-state.md): vəziyyət maşını
21. [Strategy](21-strategy.md): dəyişdirilə bilən alqoritm
22. [Template Method](22-template-method.md): alqoritmin skeleti
23. [Visitor](23-visitor.md): yeni əməliyyat əlavə etmək
